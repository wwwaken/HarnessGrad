    1 r"""GAIA (validation split): 165 web-research questions, graded by the official scorer.
    2 
    3     python3 data/datasets/gaia/prepare.py          # fetch the pool + the 42 attachments (needs HF_TOKEN)
    4     python3 data/datasets/gaia/control.py --oracle --platform
    5     python3 tools/dataset_lint.py --dataset gaia
    6 
    7 Why this dataset is worth its own docstring: it is the first one on this platform whose tasks
    8 need the **live web**, and the first whose gold is a released answer *and* whose environment is
    9 networked. Both are decisions, not defaults.
   10 
   11 The pool
   12 --------
   13 `gaia-benchmark/GAIA@682dd723ee1e1697e00360edccf2366dc8418dd9` -- the official release, gated
   14 (`gated: "auto"`: accepting its terms authorises immediately). Two splits are downloadable and
   15 only one is usable:
   16 
   17 * **validation** -- 165 rows, and **165 of them carry a real `Final answer`** (levels 53/86/26),
   18   38 with an attachment;
   19 * **test** -- 301 rows, and **all 301 carry the placeholder `"?"`** instead of an answer.
   20 
   21 `prepare.py` materializes validation into a 165-row `pool.jsonl` plus `attachments/`, and
   22 *proves* the exclusion rather than assuming it: it downloads the test parquet too, counts the
   23 placeholders, and records the count in the pool header. A scorer run over the test split would
   24 compare submissions against `"?"` and report a number; that is the failure this dataset is one
   25 step away from at all times.
   26 
   27 What the agent gets, and what it must not
   28 -----------------------------------------
   29 The question, the level, the attachment when the row names one, and a short answer-format
   30 instruction. It does **not** get `Annotator Metadata`, which is not metadata: it is a dict whose
   31 `Steps` field walks through the annotator's own search (the first row names the arXiv query, the
   32 date window and the article to open). Nor does it get `file_path`, which points inside the
   33 release tree. Both exclusions have tests.
   34 
   35 The metric
   36 ----------
   37 `question_scorer(model_answer, ground_truth) -> bool` from the official leaderboard Space
   38 (`gaia-benchmark/leaderboard`, `scorer.py`, sha256 `0d44c07f3046eec521697c22e3eaca8719cc81e422a8eaf32695c5f22bdac6e2`)
   39 -- the same function the leaderboard calls (`app.py`: `question_scorer(task['model_answer'],
   40 gold_results[...]["Final answer"])`). It travels as a `VERIFY.inputs` entry out of `_src/`, so the
   41 check calls **upstream's bytes** rather than a transcription of them: a float, a comma/semicolon
   42 list, and a string are each normalized differently, and that asymmetry is exactly what a
   43 hand-written "exact match" would get wrong. Reward is 1.0 or 0.0.
   44 
   45 The environment, and the one thing the oracle does not prove
   46 ------------------------------------------------------------
   47 GAIA runs in an `exec` container on the internal `services` network and declares `web` access.
   48 The host gateway publishes selected search/fetch providers as `HG_SVC_WEB_URL`; the task has no
   49 general internet route. Provider names and the SearXNG endpoint are recorded with the run.
   50 
   51 The oracle here is the **released** gold answer, so `ORACLE_SOURCE = "released"` and gate 1 is
   52 reachable on all 165 tasks. That is worth stating precisely: submitting the gold text proves the
   53 *check* is reachable, and it proves nothing about whether a harness can *find* the answer on the
   54 web. A score of 0 on a task whose oracle has passed is therefore still uninterpretable in the way
   55 INTERFACE §2.5 means -- the oracle control is cheap here and the interesting work is the harness's.

  135 def _raw() -> list[dict]:
  136     rows = []
  137     with (DATASET_ROOT / POOL).open(encoding="utf-8") as handle:
  138         header = json.loads(handle.readline())
  139         if header.get("rows") != ROWS:
  140             raise ValueError(f"{POOL}: header says {header.get('rows')} rows, expected {ROWS}")
  141         for line in handle:
  142             if line.strip():
  143                 rows.append(json.loads(line))
  144     if len(rows) != ROWS:
  145         raise ValueError(f"{POOL}: {len(rows)} rows, expected {ROWS}")
  146     if any(row["gold"].strip() in ("", "?") for row in rows):
  147         raise ValueError("gaia: a row carries the test split's placeholder gold; the pool must "
  148                          "be the validation split")
  149     return rows

  155 def rows() -> list[dict]:

  162                 f"`python3 data/datasets/gaia/prepare.py` (needs HF_TOKEN: the release is gated).")
  163         _RAW = _raw()
  164     return _RAW

  179 def _question(row: dict) -> str:
  180     parts = [f"# {row['question']}", ""]

  187 def _setup(row: dict) -> dict:
  188     files = [{"path": "TASK.md", "content": _question(row)},
  189              {"path": "bin/ask", "from": str(CLI)}]
  190     source = _attachment_path(row)
  191     if source is not None:
  192         files.append({"path": f"attachments/{row['attachment']}", "from": str(source)})

  203                  "--reward-file", REWARD_FILE, "--evidence-file", EVIDENCE_FILE],

  231 def __getattr__(name: str):
  232     """`ENV`, `SPLIT`, `SETUP` and `VERIFY`, built on demand.
  233 
  234     **Not at import**, for two reasons that have both already cost this repository a bug. The
  235     mechanical one: `prepare.py` imports this module before the pool exists, so an import-time
  236     read made the materializer unable to run (measured: `FileNotFoundError` on
  237     `pool.jsonl` from `data/datasets/gaia/prepare.py`). The policy one: `data/scaffolds/registry.py::published()`
  238     imports every module in `data/` to decide what the Launch form offers, and that has to work
  239     on a machine where no dataset has been provisioned (`data/datasets/spreadsheetbench.py` and
  240     `data/datasets/bird_minidev.py` carry the same guard).
  241     """
  242     if name not in _BUILT:
  243         rows_ = rows()
  244         ids = [task_id(row["index"]) for row in rows_]
  245         _BUILT.update({
  246             "ENV": {tid: dict(ENV_BASE) for tid in ids},
  247             "SPLIT": registry.default_split([{"task_id": tid} for tid in ids]),
  248             "SETUP": {task_id(row["index"]): _setup(row) for row in rows_},
  249             "VERIFY": {task_id(row["index"]): _verify(row) for row in rows_},
  250         })
  251     try:
  252         return _BUILT[name]
  253     except KeyError:
  254         raise AttributeError(f"module {__name__!r} has no attribute {name!r}") from None

  259              for row in rows()]

  261                    for task in tasks}
