    4 ``test_normal`` (168), and ``test_challenge`` (417).  The adapter uses the release's
    5 own declaration (``SPLIT_SOURCE = "declared"``), places train and dev on the study
    6 side, and scores the two test files on the eval side.  ``dev`` is included with train
    7 because the release calls both non-test files development material; this is stated here
    8 rather than silently dropping 57 released tasks.
    9 
   10 The paper-era build (Trivedi et al., ACL 2024, arXiv 2407.18901v2) reported
   11 105/60/168/417 tasks, totaling 750. The pinned release has 18 fewer train/dev
   12 tasks; both test split counts match the paper.
   13 
   14 AppWorld's environment server is a sidecar service.  The task container only gets the
   15 small ``aw`` client; the service owns the world and writes its API-call log through the
   16 platform recording mount.  A fresh verifier reads that log and replays every request in
   17 a new AppWorld world before calling the released ``ground_truth/evaluation.py``.  A
   18 process started by the agent would not survive the platform's fresh verification
   19 container, which is why the server is declared in ``services``.
   20

   22 released API-call logs are used as the oracle only for those covered tasks; uncovered

   71 def bundle_zip(bundle_path: Path | str | None = None) -> zipfile.ZipFile:
   72     """Decrypt the official bundle in memory using AppWorld's public constants."""
   73     from cryptography.hazmat.primitives import hashes
   74     from cryptography.hazmat.primitives.ciphers import Cipher, algorithms, modes
   75     from cryptography.hazmat.primitives.kdf.pbkdf2 import PBKDF2HMAC
   76 
   77     path = Path(bundle_path) if bundle_path else BUNDLE
   78     data = path.read_bytes()
   79     key = PBKDF2HMAC(
   80         algorithm=hashes.SHA256(), length=32, salt=SALT, iterations=100000
   81     ).derive(PASSWORD.encode())
   82     decryptor = Cipher(algorithms.AES(key), modes.CFB(data[:16])).decryptor()
   83     return zipfile.ZipFile(io.BytesIO(decryptor.update(data[16:]) + decryptor.finalize()))

  106 def _db_digest(root: Path) -> str:
  107     digest = hashlib.sha256()
  108     for path in sorted((root / "dbs").glob("*.jsonl")):
  109         digest.update(path.name.encode())
  110         digest.update(path.read_bytes())
  111     return digest.hexdigest()

  114 def prepare() -> Path:
  115     """Decrypt/materialize the release and write compact per-task metadata.
  116 
  117     The heavy task databases stay under the external dataset root.  Importing this adapter
  118     reads only ``pool.jsonl``; it does not walk the 14,696-member archive or task trees.
  119     """
  120     UNPACKED.mkdir(parents=True, exist_ok=True)
  121     marker = UNPACKED / "data" / "version.txt"
  122     if not marker.is_file():
  123         with bundle_zip() as archive:
  124             for member in archive.infolist():
  125                 target = UNPACKED / member.filename
  126                 if member.is_dir():
  127                     target.mkdir(parents=True, exist_ok=True)
  128                     continue
  129                 target.parent.mkdir(parents=True, exist_ok=True)
  130                 with archive.open(member) as source, target.open("wb") as destination:
  131                     shutil.copyfileobj(source, destination)
  132 
  133     rows: list[dict] = []
  134     declared = split_ids(BUNDLE)
  135     for split, ids in declared.items():
  136         for task_id in ids:
  137             root = UNPACKED / "data" / "tasks" / task_id
  138             specs = json.loads((root / "specs.json").read_text())
  139             metadata = json.loads((root / "ground_truth" / "metadata.json").read_text())
  140             rows.append(
  141                 {
  142                     "task_id": task_id,
  143                     "split": split,
  144                     "difficulty": metadata["difficulty"],
  145                     "num_api_calls": metadata["num_api_calls"],
  146                     "num_apps": metadata["num_apps"],
  147                     "instruction": specs["instruction"],
  148                     "dbs": _db_digest(root),
  149                     "released_oracle": (root / "ground_truth" / "api_calls.json").is_file(),
  150                 }
  151             )
  152     POOL.parent.mkdir(parents=True, exist_ok=True)
  153     with POOL.open("w", encoding="utf-8") as output:
  154         for row in sorted(rows, key=lambda value: value["task_id"]):
  155             output.write(json.dumps(row, ensure_ascii=False, sort_keys=True) + "\n")
  156     return POOL
  157

  159 def _pool() -> list[dict]:
  160     if not POOL.is_file():
  161         prepare()
  162     actual = hashlib.sha256(POOL.read_bytes()).hexdigest()
  163     if actual != POOL_SHA256:
  164         raise ValueError(f"appworld: pool digest {actual} != pinned {POOL_SHA256}")
  165     return [json.loads(line) for line in POOL.read_text(encoding="utf-8").splitlines() if line.strip()]

  172 def oracle_files(task: dict) -> dict[str, str]:
  173     task_id = task["task_id"]
  174     if task_id not in _oracle_ids():
  175         raise ValueError(
  176             f"appworld: no released reference for {task_id}; coverage={ORACLE_COVERAGE}"
  177         )
  178     path = UNPACKED / "data" / "tasks" / task_id / "ground_truth" / "api_calls.json"
  179     if not path.is_file():
  180         raise ValueError(f"appworld: released API-call log missing for {task_id}")
  181     calls = json.dumps(json.loads(path.read_text()))
  182     return {"reference.py":
  183             f"import json\ncalls = json.loads({calls!r})\n" +
  184             "for call in calls:\n" +
  185             "    method = call.get('method', 'get').lower()\n" +
  186             "    requester_call = f\"requester.{method}({call['url']!r}, data={call.get('data') or {}!r}, client=requester.client)\"\n" +
  187             "    exec(requester_call)\n"}

  206 def _runtime_prompt(task_id: str) -> str:
  207     task_arg = shlex.quote(task_id)
  208     action = f"./aw action --task {task_arg} --code"
  209     discovery = action + " 'print(apis.api_docs.show_app_descriptions())'"
  210     return f"""AppWorld provides a shell CLI in the working directory: ./aw.
  211 Use your harness's shell/command tool to run these commands; Python snippets
  212 belong in --code, not in the local shell or a local Python process.
  213 
  214 Initialize once: `./aw init --task {task_arg}`
  215 This returns the task, supervisor identity and current datetime. Reinitializing
  216 resets the world, so keep using action after initialization.
  217 
  218 Execute Python in the service: `{action} '<python>'`
  219 The service interpreter already defines `apis`. Variables and API state persist
  220 between action calls. Each action executes a whole Python snippet, which may
  221 include multiple API calls, assignments, loops and conditionals. Print the
  222 responses you need to inspect; one action is not one API call. Local files and
  223 imports do not provide AppWorld APIs.
  224 
  225 Start discovery with this executable API action: `{discovery}`
  226 Then discover the relevant app's methods with
  227 `apis.api_docs.show_api_descriptions(app_name="<discovered app>")` and inspect
  228 parameters with `apis.api_docs.show_api_doc(app_name="<discovered app>",
  229 api_name="<discovered API>")`, each inside a printed --code action.
  230 Call the documented methods as `apis.<app>.<api>(...)`. Discover supervisor
  231 APIs for account credentials when needed; use returned values and documented
  232 parameters rather than guessing method names, passwords or IDs.
  233 
  234 Perform the requested changes through these API actions, inspect their results,
  235 then give your final answer through your harness. A local script, plain text
  236 answer or print-only snippet does not change the world. The service records API
  237 calls automatically; its recording is not an actor file to create or edit.
  238 CLI syntax help: `./aw --help` and `./aw action --help`.
  239 """
